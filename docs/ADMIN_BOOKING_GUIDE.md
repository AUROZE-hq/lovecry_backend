# Admin booking guide

1. Log in at `/admin` (temp password `ADMIN_TEMP_PASSWORD`).
2. Open **Counselling** (`/admin/counselling`).
3. Set weekly windows on **Availability**; add vacation/blocks.
4. Tune duration/buffers/notice on **Settings**.
5. Manage consent versions on **Consent forms**.
6. View/cancel/complete appointments under **Appointments**.
7. Check **Google** status before expecting Calendar/Drive sync.

Public booking: `/book-now`.
