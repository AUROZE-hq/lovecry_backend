# Counsellor Google Calendar guide

1. Open Google Calendar (mobile or desktop) signed into the LoveCry Workspace account.
2. Ensure **LoveCry Counselling Appointments** calendar is visible/subscribed.
3. Events appear as `Counselling Appointment — LC-APT-…` with client contact in the description (minimal).
4. Changing time or deleting an event will sync back once push notifications / reconciliation are enabled (after Google credentials).
5. Clinical notes must not be stored in Calendar descriptions — use the LoveCry admin record link when available.
